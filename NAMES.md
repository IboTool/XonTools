# Names

Terms that later specs inherit.

## For A2

- **Assertion and hard clamp** (from A1 rev. 2.1's harmony re-specification). Claims from agent sources
  (reports, beliefs, plan steps) are assertions: each carries the assertion term μ (x_i − 1)², with μ = 1, so a
  contradicted assertion costs energy instead of flipping to false for free. Trusted observations and user or
  system intents are the hard clamps (x_i = +1). In A1 the hard clamps are premises and user-marked evidence,
  asserted claims carry the μ term, and quoted claims carry neither.
